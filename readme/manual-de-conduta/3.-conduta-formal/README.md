# 👤 3. Conduta Formal

A **conduta formal** representa o padrão de comportamento esperado de todo policial, <mark style="color:$success;">**dentro e fora de serviço.**</mark>

Nesta seção, são abordadas as normas de postura, respeito, ética e apresentação que refletem a imagem da corporação perante a sociedade.

{% hint style="info" %}
**O cumprimento dessas condutas é essencial para preservar a credibilidade, a disciplina e o profissionalismo da instituição.**
{% endhint %}
