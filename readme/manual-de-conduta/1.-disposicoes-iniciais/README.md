# 📌 1. Disposições Iniciais

As disposições iniciais apresentam os princípios fundamentais que regem o comportamento e o funcionamento da Polícia da Cidade Rise.

Este capítulo define os <mark style="color:orange;">valores, deveres e responsabilidades</mark> que orientam todos os policiais no exercício de suas funções, estabelecendo as bases da <mark style="color:orange;">hierarquia, disciplina e legalidade</mark> dentro da corporação.

{% hint style="info" %}
O objetivo é garantir que cada membro compreenda o papel que exerce na manutenção da ordem, da justiça e da imagem institucional da polícia.
{% endhint %}
